# `nixtrix`

*By [impurify](https://impurify.com/).*

This is a place to collect hacks and kludges.

More precisely, it’s a place to collect the minimal cases used to experiment.  These usually wind up in `/tmp` and discarded.  They should be saved.

It’s likely that most documentation, if any, will wind up in the commit logs.  I do appreciate an informative commit log.

Most people would use Gists for this, but I don’t want to be dependent on Github.  A monorepo of quasi-gists is more portable.
